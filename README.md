# CAPPA App Hub

Static multilingual download catalogue for CAPPA applications. The site links to official GitHub Releases.

Languages: Turkish, English, Russian, Arabic, Simplified Chinese, and Indonesian.

Current Windows release: CAPPA Flash v1.2.04.

Current CAPPA Boost release: v1.0.24 for Windows x64.

License help is published at `/help/license/`; the site carries its selected language in the URL fragment. The guide is self-contained and the six matching PDFs can also be downloaded from that directory.

CAPPA Flash Windows: 1–3 engines, 0 s or 1 s TAP intervals, on-chain PROOF result recovery, and wallet-name licensing with signed license-file import. Automatic checkout covers up to 200 wallets per invoice.
The home page shows the CAPPA Flash header with sample data.

Android downloads include CAPPA Flash 1.0.96 (build 6000037) and CAPPA Eagle 1.0.96 (build 6000034). Both are universal ARM APKs for Android 7 and later. Flash offers 0/1 s TAP intervals (default 0 s).

The current CAPPA Flash Windows user guide is at /help/flash/, with a PDF for each supported language.
