# CAPPA App Hub

Static multilingual download catalogue for CAPPA applications. The site links to official GitHub Releases.

Languages: Turkish, English, Russian, Arabic, Simplified Chinese, and Indonesian.

Current Windows release: CAPPA Eagle v1.1.2.

Current CAPPA Boost release: v1.0.15 for Windows x64.

License help is published at `/help/license/`; the site carries its selected language in the URL fragment. The guide is self-contained and the six matching PDFs can also be downloaded from that directory.

CAPPA Eagle Windows: unlimited saved wallets and public reads; automatic purchase selection 1–200; verified manual-license renewal import; daily epoch pause 2–12 hours/local time; engine selection 1–12.
The home page shows the CAPPA Eagle header with sample data.

Current Android release: CAPPA Eagle 1.0.94, build 6000030, universal ARM APK for Android 7 and later. The computation window is 155 seconds.
