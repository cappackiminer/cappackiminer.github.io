# CAPPA App Hub

Static multilingual download catalogue for CAPPA applications. The site links to official GitHub Releases.

Languages: Turkish, English, Russian, Arabic, Simplified Chinese, and Indonesian.

Current Windows release: CAPPA hardworker v1.0.88.

License help is published at `/help/license/`; the site carries its selected language in the URL fragment. The guide is self-contained and the six matching PDFs can also be downloaded from that directory.

Public 1.0.88 documentation: unlimited saved wallets and public reads; automatic purchase selection 1–200; verified manual-license renewal import; daily epoch pause 2–12 hours/local time; engine selection 1–4.
The visible payment screenshot uses fictional wallets/invoice, all native IPC inert and network blocked. No real activation is claimed.
